# GitHub Pages Deployment

A GitHub Actions workflow that automatically deploys a website to GitHub Pages whenever `index.html` is updated.

## Repo where I have all the files at

https://github.com/MikaelEramian/gh-deployment-workflow

## How it works

Any push to main that changes index.html triggers the workflow which deploys the site automatically.
